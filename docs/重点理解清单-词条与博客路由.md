# 重点理解清单：词条与博客路由合并

## 统一规则

- **正文 / 版本 / 渲染**：common 与 blog 共用 `entries` + `entry_versions` + `WikiEntry`
- **类型 `type`**：创建时选定（`common` | `blog`），之后不可变
- **URL**：
  - common：`/entry/{slug…}`（物化 `entries.href` 直查）
  - blog：`/entry/blog/{slug}`（一级，slug 在 blog 命名空间内唯一；href 同样入库）
- **身份键**：阅读路径只用规范 `href` / slug，不用 UUID 当 URL 段

## 创建 UX

1. 选类型：百科 / 博客
2. 百科 → `ParentEntryPicker`（底部固定「顶级词条 /」= `parentId null`）
3. 博客 → 前缀锁死 `/entry/blog/`，无父级选择器

## 关键入口

| 能力 | 位置 |
|------|------|
| 统一路径解析 | `getEntryPageDataByHref` |
| href 构建 / 物化 | `resolveEntryHref` / `entries.href` |
| 创建页 | `EntryEditor` + `EntryPublishTargetPicker` + `ParentEntryPicker` |
| 索引 | `entries_href_unique` / `entries_common_root_slug_unique` / `entries_blog_slug_unique` |

## 自测

- [ ] `/entry/blog/react-19-release` 可读
- [ ] `/entry/blog/{uuid}` 应 404（不再兼容）
- [ ] 新建博客发布后跳到 `/entry/blog/{slug}`
- [ ] 新建百科选「顶级」→ `/entry/{slug}`；选父级 → `{parent}/{slug}`
- [ ] 父级搜索只出 common；列表底部始终有「顶级词条」
- [ ] 改父级/slug 后子孙 `href` 级联更新，旧 path 可走 redirects

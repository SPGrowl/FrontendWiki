# 重点理解清单：代码块与沙盒

面向本仓库「Markdown 代码块 → 在沙盒中运行」能力的速查清单。
HTML Playground 为实验性功能（分支 `experimental/html-playground`）。

---

## 1. 整体链路

- [ ] 词条正文 / 编辑预览都走 `EntryContent` → `react-markdown`。
- [ ] `remarkWikiFences` 解析围栏 meta、隐藏 `full` 块、给展示块写入运行信息。
- [ ] 块级 `code` 映射到 Client 组件 `MarkdownCodeBlock`。
- [ ] 有 `sandbox` + `runPayload` 时显示「在沙盒中运行」。
- [ ] JS 沙盒：`openRunner({ code })` → `JsRunnerPanel`（只注入，不自动跑）。
- [ ] HTML 沙盒：`openPlayground({ html })` → `HtmlPlaygroundPanel`（只注入，不自动跑）。

```
Markdown 围栏
  → remarkWikiFences（配对 id / 隐藏 full）
  → EntryContent (components.code)
  → MarkdownCodeBlock
       ├ sandbox=js   → openRunner({ code: payload })
       └ sandbox=html → openPlayground({ html: payload })
```

## 3. 块级 vs 行内代码

必须分清，否则行内 `` `code` `` 会被误渲染成大块：

| 条件 | 视为 | 渲染 |
|------|------|------|
| `className` 含 `language-xxx` | 块级 | `MarkdownCodeBlock` |
| 文本含换行 `\n` | 块级 | `MarkdownCodeBlock` |
| 其余 | 行内 | 默认 `<code>` |

`pre` 组件刻意写成 `<>{children}</>`，避免 `pre > MarkdownCodeBlock` 双重外壳。

---

## 4. 运行按钮判定

展示块语言决定「有没有资格」；完整块语言决定「进哪个沙盒」。

| 展示块语言 | 没有匹配到合法 `full` | 匹配到合法 `full` |
|-----------|----------------------|-------------------|
| `js` / `javascript` / `mjs` / `cjs` / `jsx` | 显示按钮，注入自身，JS 沙盒 | 注入 `full` 正文，沙盒由 `full` 语言决定 |
| `html` / `css` | **不显示按钮** | 注入 `full` 正文，沙盒由 `full` 语言决定 |
| `ts` / `python` / 其它 | 不显示 | 不显示 |

合法 `full` 语言：

| `full` language | 沙盒 |
|-----------------|------|
| js 族 | JS Runner |
| `html` | HTML Playground |
| `css` 或其它 | 视为未匹配（没有 CSS 沙盒，也不自动包 HTML） |

多个展示块可以共用同一个 `id` 的 `full`。同一 `id` 出现多个 `full` 时使用 **先出现的**。

作者写法：

````markdown
```js
console.log(1 + 2);
```

```css id=card-mq
.card { display: grid; }
@media (max-width: 640px) {
  .card { grid-template-columns: 1fr; }
}
```

```html full id=card-mq
<!DOCTYPE html>
<html>
<body>
  <div class="card">A</div>
</body>
</html>
```
````

`full` 块默认不渲染。复制按钮始终复制展示块内容。

## 5. Context API 约定

```ts
openRunner();                    // 侧栏：只打开，不改 JS 编辑器
openRunner({ code: "..." });     // 代码块：打开并注入 JS
openPlayground();                // 侧栏：只打开，不改 HTML 编辑器
openPlayground({ html: "..." }); // 代码块：打开并注入 HTML
```

- `pendingCode` / `pendingHtml` 是一次性队列：Panel 读入后必须 clear。
- 「在沙盒中运行」**不会**自动执行；需再点运行或 Ctrl/⌘+Enter。

---

## 6. 安全与边界

- [ ] 两个沙盒 iframe 均 `allow-scripts`，无 `allow-same-origin`。
- [ ] HTML Playground 额外 `allow-modals`（便于 `alert` 演示）。
- [ ] JS Runner 默认有执行超时。
- [ ] 剪贴板 API 失败时复制按钮静默失败。

---

## 7. HTML Playground UI

- 左栏编辑完整 HTML，右栏 `iframe.srcDoc` 预览。
- `react-resizable-panels`（`Group` / `Panel` / `Separator`）拖动分隔条；预览宽度变化时媒体查询跟随 iframe 视口。
- 标题栏显示当前预览宽度（px）。

---

## 8. 样式注意点

- 块级外观由 `.wiki-code-block` 负责；`.wiki-prose pre` 通用样式已去掉。
- 行内 `code` 仍用 `.wiki-prose :where(code)`。
- 预览区复用同一 `EntryContent`，编辑时即可试跑示例。

## 9. 自测清单

- [ ] ` ```js ` 无 id：出现运行按钮，注入自身到 JS 运行器。
- [ ] ` ```js id=a ` + ` ```js full id=a `：注入 full 到 JS 运行器；页面上看不见 full。
- [ ] ` ```js id=a ` + ` ```html full id=a `：打开 HTML Playground，注入 full。
- [ ] ` ```css id=a ` 与 ` ```html id=a ` 共用同一 `html full`：两个展示块都有按钮，载荷相同。
- [ ] 孤立 ` ```html ` / ` ```css `：无运行按钮。
- [ ] ` ```css id=a ` + ` ```css full id=a `：无运行按钮。
- [ ] ` ```ts ` / ` ```python `：无运行按钮，仍可复制。
- [ ] 侧栏「JS 运行器」「HTML Playground」无参打开时，不覆盖已编辑内容。
- [ ] 行内 `` `foo` `` 仍是行内样式。
- [ ] 拖动 Playground 右栏，媒体查询随预览宽度变化。
- [ ] 阅读页与编辑预览行为一致。
